# ניהול תקציב

אפליקציית Android לניהול הכנסות, הוצאות ותקציב אישי, בעברית ובכיווניות RTL.

## דרישות
- Android 8.0 (API 26) ומעלה
- כל הנתונים נשמרים מקומית ב-SQLite
- האפליקציה אינה מבקשת הרשאת אינטרנט ואינה תלויה בשרת

## יכולות
- מסך ראשי עם יתרה, הכנסות והוצאות
- ניהול תנועות, חיפוש, עריכה ומחיקה עם אישור
- קטגוריות עם אייקוני Emoji ותקציבים
- תקציב חודשי ושנתי
- סטטיסטיקה לפי תקופה וקטגוריה
- הפיכת כל תנועה להוראה מחזורית בזמן ההזנה
- קטגוריות השקעות ורווחי השקעות
- נעילת PIN מאובטחת בעת יציאה וחזרה לאפליקציה
- גיבוי מלא JSON, שחזור וייצוא CSV

## בנייה
הרץ: gradle --no-daemon :app:assembleRelease

ה-APK נמצא בתיקייה app/build/outputs/apk/release/.

## חתימה ועדכונים
תהליך הפרסום שומר את מפתח החתימה של CI ומשווה בכל בנייה את טביעת האצבע שלו לזו של הגרסה היציבה האחרונה. אם המפתח חסר או שהחתימה אינה תואמת, הפרסום נעצר כדי למנוע יצירת APK שלא ניתן להתקין כעדכון.

הגרסאות הראשונות (לפני שמירת מפתח קבוע) נחתמו במפתח זמני שונה. מעבר מהן לגרסה החתומה הנוכחית מחייב גיבוי JSON, הסרת ההתקנה הישנה והתקנת הגרסה החדשה. לאחר המעבר לגרסה החתומה הנוכחית, העדכונים הבאים יהיו תואמים כל עוד מפתח החתימה הקבוע נשמר.
